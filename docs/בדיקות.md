# בדיקות ידניות

בלי Vitest/Playwright. הכל בדפדפן מול הדמו. תוצאות עם `JSON.stringify` מופיעות בטוסט וב-console (F12).

## הרצה

1. פתח טרמינל **בשורש הפרויקט** (התיקייה שמכילה את `src/` ואת `demo/`).
2. ודא שיש `dist/` עדכני (`npm run build`).
3. הרץ:

```
python -m http.server 5502
```

4. בדפדפן פתח:

```
http://127.0.0.1:5502/demo/
```

הדמו טוען IIFE + CSS מ־`dist/`, לא מ־`src/`. אם הפורט תפוס, החלף ל-`5503` ואת המספר בכתובת.

כפתור **LTR** מחליף כיוון. כפתור ערכת הנושא מחליף מערכת / בהיר / כהה (`data-fb-theme`). כדאי לעבור על תרחיש אחד ב-RTL ואחד ב-LTR.

## רשימת תרחישים

הכפתורים הם בשורת **בדיקות חוזה**, חוץ מתור/טוסטים שכבר קיימים ב«תור וכפילויות».

### 1. תור — דיאלוג אחד בכל רגע

- כפתור: **תור ו־Enter**
- פעולה: Enter על הראשון (הכפתור בפוקוס).
- צפוי: נסגר פעם אחת; מופיע רק «שני». לא שני דיאלוגים יחד.
- המשך: סגור שני ושלישי. ברביעי (confirm) סגור ב-X — התור נגמר, אין דיאלוג תקוע.

### 2. Esc כפול (Chrome)

- כפתור: **תור ו־Enter**
- פעולה: על הדיאלוג הראשון, Esc ואז Esc מיד שוב.
- צפוי: אנימציית סגירה, Promise נפתר, הדיאלוג הבא בתור מופיע. התור לא נתקע.

### 3. חוזה `confirm` — תמיד boolean

- כפתור: **חוזה אישור**
- פעולה: פעם אישור, פעם ביטול, פעם X, פעם Esc.
- צפוי:
  - אישור → `confirm: true ("boolean")`
  - ביטול / X / Esc → `confirm: false ("boolean")`
  - אף פעם לא `null`

### 4. חוזה `prompt` / ביטול

- כפתור: **ביטול קלט**
- פעולה: X, Esc, ביטול; ואז שוב עם טקסט ואישור.
- צפוי: ביטול → `prompt: null ("object")`. אישור → המחרוזת שהוקלדה.

### 5. `menu` עם `0` / `''` / `false`

- כפתור: **ערכי קצה בתפריט**
- פעולה: ללחוץ על כל אחד משלושת הכפתורים, ובפעם רביעית על ביטול.
- צפוי:
  - אפס → `menu: 0 ("number")`
  - מחרוזת ריקה → `menu: "" ("string")`
  - false → `menu: false ("boolean")`
  - ביטול / X → `menu: null ("object")`

### 6. סינון selector ובחירה

- כפתור: **סינון ברשימה**
- פעולה: הקלד `תפ`. אמור להישאר רק «תפוח». Enter אמור למקד את הפריט הגלוי; בחירה.
- צפוי: `selector: "apple" ("string")`. ניקוי החיפוש מחזיר את שלושת הפריטים. ביטול → `null`.

### 7. טקסט מסוכן (`<` ו-`"`)

- כפתור: **טקסט מסוכן**
- פעולה: פתח וקרא כותרת והודעה; אשר; בדוק את ה-prompt (ברירת מחדל עם מרכאות); אשר או בטל; בדוק טוסט.
- צפוי: `<b>bold</b>` ומרכאות מוצגים כטקסט, לא כ-HTML. אין `alert` שקופץ מהמחרוזת. `\n` בהודעה נשבר לשתי שורות (`pre-line`). ב-prompt מופיע מילולית `a" onfocus="alert(1)`. בטוסט אותו כלל.

### 8. טוסטים

- כפתור: **שישה טוסטים** (בתור וכפילויות)
- צפוי: לכל היותר 5 מוצגים; **הישן** נסגר (לא החדש). החדש על הקצה; הישנים זזים פנימה באנימציה. X / תפוגה: יציאה קצרה והאחרים ממלאים את החור בלי קפיצה. הודעה ארוכה נשברת לשורות בתוך הרוחב המקסימלי. מעבר עכבר עוצר את הטיימר. טוסט נשאר מעל דיאלוג פתוח (למשל אחרי **טוסטים ודיאלוגים יחד**).

### 9. `size`

- כפתור: **גדלים צר ורחב**
- צפוי: דיאלוג ראשון צר מ־md. אחרי אישור — טופס רחב יותר מ־md, לא נחתך ב־400px.

### 9ב. `vars`

- כפתור: **משתני CSS**
- פעולה: דיאלוג ראשון רחב (~32rem) עם כפתור בצבע אחר; אחרי אישור — alert רגיל בלי `vars`.
- צפוי: הראשון לא md ולא lg של `size`. השני חזר לרוחב ולצבע ברירת מחדל. לא דולף.
- קונסול: `Feedback.alert({ message: 'x', vars: { width: '20rem' } })` → throw סינכרוני `Error('Feedback: invalid CSS variable')` (לא Promise). `vars: []` → `Error('Feedback: invalid dialog vars')`.

### 10. `closeAll`

- כפתור: **סגירת הכול**
- פעולה: נפתח דיאלוג ראשון; אחרי ~400ms הכל נסגר לבד.
- צפוי: רק דיאלוג אחד על המסך בזמן הפתיחה. אחרי `closeAll`: אין דיאלוג פתוח, אין הבא בתור.
  - `closeAll-1: undefined ("undefined")`
  - `closeAll-2: false ("boolean")`
  - `closeAll-3: null ("object")`

### 11. שפה מובנית (`setLocale`)

- פעולה: בקונסול (`F12`) `Feedback.setLocale('en')`, ואז בדמו דיאלוג בלי כותרת מותאמת (למשל **הודעה פשוטה** / alert מחרוזת). אחר כך `Feedback.toast.info('x')` ובדוק aria-label של ה-X. החזר `Feedback.setLocale('he')`.
- צפוי אחרי `'en'`: כותרת alert `Message`, כפתור `OK`, X בדיאלוג `Close dialog`, X בטוסט `Close`. אחרי `'he'`: `הודעה` / `אישור` / `סגור חלון` / `סגור`.
- אובייקט חלקי: `Feedback.setLocale({ ok: 'OK' })` — רק אישור באנגלית, שאר המפתחות עברית.
- `Feedback.setLocale('fr')` → זריקת `Error('Feedback: invalid locale')`.

### 12. טופס — טיפוסים וצ'קבוקס

- כפתור: **טופס פרופיל** (וריאציות)
- פעולה: מלא שם, השאר גיל ריק, בטל «קבלת עדכונים», אשר. F12 → `Profile Data Updated`.
- צפוי: המפתח `age` קיים וערכו `undefined` (לא `null`, לא נמחק מהאובייקט). `newsletter: false`, `dept` מחרוזת, `notes` מחרוזת. `JSON.stringify` משמיט מפתחות `undefined`.
- קונסול: `Feedback.form({ fields: [{ name: 'doc', label: 'קובץ', type: 'file' }] })` → דחיית Promise `Error('Feedback: סוג שדה לא תקין: "file"')`, בלי דיאלוג. אותו דבר ל־`Feedback.prompt({ message: 'x', type: 'file' })`.

### 13. `closeOnBackdrop`

- כפתור: **סגירה ברקע** (וריאציות, וגם בבדיקות חוזה)
- פעולה:
  1. לחץ מלא על הרקע (down ו-up שם) — אמור להיסגר.
  2. פתח שוב: לחץ בתוך הקופסה, גרור לרקע, שחרר — לא אמור להיסגר. אחר כך X.
  3. דיאלוג רגיל בדמו (בלי הדגל): לחיצה על הרקע רק מנענעת, לא סוגרת.
  4. ויזואלית עם הדגל: עמעום רקע עדין ובלי blur; בלי הדגל — עמעום חזק כרגיל.
- צפוי אחרי סגירה מהרקע בבדיקות חוזה: `backdrop-confirm: false ("boolean")`.

### 14. מיקום טוסטים

- כפתור: **מיקום טוסט** — מסיר טוסטים קיימים מיד (בלי אנימציית יציאה), עובר למיקום הבא, ומציג **טוסט אחד**. אין אקראיות. מהלחיצה השנייה עדיין טוסט אחד, בלי שכבה של הקודם.
- צפוי: שישה מיקומים נפרדים. `end` ממול ל-`start` (לא אותו צד). ב-RTL `start` בצד ימין, ב-LTR בשמאל. כניסה ב-start/end מהצד, ב-center מלמעלה או מלמטה.
- קונסול: `Feedback.setToastPosition('left')` → `Error('Feedback: invalid toast position')`.
- `Feedback.getToastPosition()` אחרי לחיצה תואם למה שמוצג.

### 15. `urgent` — חניה בלי resolve

- כפתור: **דחוף (חניה)**
- פעולה: נפתח prompt. הקלד טקסט. אחרי ~6s קופץ alert דחוף. סגור אותו — אמור לחזור ה-prompt עם אותו טקסט. אשר/בטל. רק אז confirm שהיה בתור הרגיל.
- צפוי:
  - אף פעם לא שני דיאלוגים יחד.
  - סדר: דחוף → prompt (עם הטקסט) → confirm. לא confirm לפני ה-prompt.
  - `urgent-alert: undefined`
  - אחרי prompt: `urgent-prompt:` והמחרוזת (או `null` בביטול).
  - אחרי confirm: `urgent-confirm: true` או `false`.
  - מחרוזת `Feedback.alert('x')` לא דוחפת לתחילת התור.
